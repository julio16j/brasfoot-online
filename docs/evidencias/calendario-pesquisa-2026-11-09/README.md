## Uso dos auxiliares

São fontes de diagnóstico, não uma suíte autossuficiente nem arquivos para inserir em src/tests do produto. Para repetir, preparar uma pasta descartável com recursos do jogo sem saves do usuário, o JAR/agent/bibliotecas identificados, subpastas classes e src/brasfoot. Remover apenas o sufixo .txt dos auxiliares copiados nessa pasta.

As orquestrações leem probe-config.json local com java (executável Java 8) e classpath (classes auxiliares, brasfoot-online.jar e lib/*.jar, separados por ponto e vírgula no Windows). O caminho do compilador ECJ e o diretório do repositório usados no script refletem este ambiente e precisam ser ajustados se ele mudar. As credenciais são obtidas em execução do host temporário; não há token fixo nos arquivos preservados.

Os probes de fontes usaram source-classes antes do JAR no classpath, compiladas da cópia identificada em fontes-identificadas.json. Os conectados usaram o pacote, sem essa precedência. Não usar uma compilação posterior do repositório e apresentar o resultado como repetição byte a byte dos mesmos artefatos. As saídas anteriores permanecem evidência das versões identificadas.
