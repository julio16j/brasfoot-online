# Catálogo autoritativo de “Atuando no”

A Procura recebia países de `SR.N()` local, que pode estar vazio ou ter outra ordem que a carreira do host. A resposta autenticada de sessão já inclui `sessionOptions.leagueCountries`; `NativeClient` agora entrega esse catálogo à janela antes do uso. O combo mantém o ID e o rótulo de cada opção, e a captura envia o ID selecionado. O valor “Qualquer” continua omitindo o filtro. Países não reconhecidos como opção com ID não são enviados como filtros válidos.

`NativeTransferSearchTest` valida ID estável e rejeita uma opção sem identidade. `NativePlayerSearchTest` confirma consulta host com país válido e rejeição de ID desconhecido. `NativePlayerSearchWindowTest` confirma na UI que a opção escolhida envia o ID anunciado pelo host e compara os resultados ao predicado nativo; todos passaram também contra `dist/brasfoot-online.jar`. JAR e ZIP reconstruídos; ZIP com 22.735 entradas e `testzip()` sem erro.
